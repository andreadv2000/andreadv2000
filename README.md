## Selected projects

### Bayesian Hierarchical Modeling of U.S. Real Estate Listing Prices

Compared three Bayesian regression models in R and JAGS, from a pooled baseline to a hierarchical model with state and ZIP-code effects and varying residual variance. All three models used the same train/test split.

On the held-out set, the final model reduced RMSE from 0.762 to 0.424 on the standardized log-price scale, a 44% reduction relative to the pooled baseline. Its 95% posterior predictive intervals achieved 95.4% empirical coverage.

### Mammography Mass Classification with CBIS-DDSM

Academic project for Fundamentals of Data Science at Sapienza. The project explored benign versus malignant mass classification using mammography images. It compared CNN architectures, including DenseNet121 and EfficientNet-B4, with boosting approaches, and used saliency maps to inspect which image regions influenced predictions.
